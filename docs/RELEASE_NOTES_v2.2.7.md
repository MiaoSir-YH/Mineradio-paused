# Mineradio 2.2.7

Windows x64 安装包为 `Mineradio-2.2.7-Setup.exe`。更新前请从托盘完全退出正在运行的 Mineradio。

## 十段均衡器

- 点击播放控制条的均衡器图标，在 31.5 Hz 到 16 kHz 的十个频段上调节音色，每段可调 ±12 dB。
- 内置平直、低音增强、人声、摇滚、流行、电子和爵士预设。手动调节会保存为自定义曲线。
- 启用状态、预设和自定义曲线会自动保存。关闭浮层后均衡器继续生效，重启后恢复上次设置。
- 浮层沿用底栏的玻璃样式，控件随主题色变化，窄窗口把滑杆排成两行。

## 播放

- 移除 Cuefield 自动混音。专辑无缝切歌时，两首歌共用同一套用户均衡器设置。
- 均衡器作用于 Web Audio 主输出。播放回退到系统直出时会绕过均衡器。

安装包的 SHA-256 校验值及构建验证结果随发布一同提供。
