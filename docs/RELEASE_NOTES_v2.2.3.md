# Mineradio 2.2.3

Windows x64 完整安装包：`Mineradio-2.2.3-Setup.exe`。

本版扩展桌面和任务栏歌词的显示、调节与交互。安装更新前，请从托盘完全退出正在运行的 Mineradio。

## 桌面与任务栏歌词

- 桌面歌词和任务栏歌词使用独立开关，可以分别显示，也可以同时显示。
- 任务栏歌词可选择多个显示屏；每个屏幕可以独立保存歌词位置、大小、透明度、天际屏词云间距以及跟随、普通或天际屏样式。
- 在任务栏歌词上直接左右拖动可调整位置；双击切换下一首，三击切换上一首。歌词以外的透明区域保留鼠标穿透。
- 任务栏歌词沿用歌词播放进度、逐字高亮和相关动画；开启翻译时，普通歌词可同时显示译文。
- 桌面歌词支持更小字号，桌面天际屏的词云字号和模糊会随桌面歌词大小调整。任务栏天际屏则使用该屏幕独立的歌词大小。
- 调大任务栏天际屏词云间距时，在任务栏空间允许的范围内扩展显示区域，中央歌词保持原来的屏幕位置。超宽歌词会缩小以完整显示。

旧版选择任务栏显示的设置会迁移到新配置，并保留原显示屏、位置和相关外观参数。显示屏暂时离线时，其选择和参数会保留；重新可用时会再次尝试显示。

## 使用范围与验证

任务栏歌词面向 Windows 横向任务栏；没有可用横向任务栏的屏幕不会显示任务栏歌词。任务栏空间有限，特别长的歌词可能缩得较小；在极窄的词云通道里，多个词仍可能相互重叠。

本版已进行自动回归、离屏渲染以及单屏 Windows 任务栏实测。多屏和混合 DPI 场景已有模拟测试，尚未完成真实双屏或混合 DPI 实机验证。安装包的构建与检查结果以对应发布附件中的 build-info 为准。
