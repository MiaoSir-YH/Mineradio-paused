# Mineradio 2.2.6

Windows x64 完整安装包为 `Mineradio-2.2.6-Setup.exe`。

安装更新前，请从托盘完全退出正在运行的 Mineradio。

## 本次更新

- 修复部分 QQ 账号头像无法显示的问题。头像不可用时显示默认占位。
- 昵称和会员状态保持原有显示，其他来源头像继续使用既有代理。

## BrimDeck 频谱

已在正式安装环境及具有开始菜单身份注册的测试包中验证播放识别和频谱显示。直接运行解包目录可能因缺少 Windows 应用身份注册而无法被 BrimDeck 识别，建议使用正式安装包并从开始菜单启动。音频服务沿用原有配置。

## 验证

头像修复已通过 12 测试包的用户实测及隔离加载、失败回退检查。正式构建的自动回归和启动检查结果以对应发布附件中的 build-info 为准。
