# Mineradio 2.2.2 验证版

Windows x64 完整安装包：`Mineradio-2.2.2-Setup.exe`。

本版用于验证通用媒体接口及全仓审查修复，保留正式版应用标识，可以更新现有 Mineradio 安装。

- 新增标准 Media Session：向系统发布曲名、歌手、专辑、封面、播放状态和时间线，并接收播放/暂停、上下首和拖进度指令，供 BrimDeck 等通用媒体控制器使用。
- 修复切歌过程中暂停被后续启动流程覆盖、音频元素替换后状态丢失等媒体控制边界。
- 修复全仓审查确认的 18 项问题，涵盖队列与换源竞态、HTTP 断流、安装升级与卸载清理、重启、二维码、摄像头、背景、书架、汽水音质与缓存。
- 更新受影响的生产依赖，修正旧测试断言并补充回归测试。

BrimDeck 的普通播放器歌词根据曲名、歌手在线匹配，并用系统时间线同步。标准媒体接口没有歌词传输字段；无法保证第三方词库匹配到所有歌曲，也不直接传输 Mineradio 的原词、翻译或逐字歌词。

安装后请在 BrimDeck 选择 Mineradio，验证封面、播放/暂停、上下首、拖动进度，以及歌词匹配与同步。

安装包在 GitHub Windows 环境从 `v2.2.2` 标签完整构建。全仓回归、真实 Electron 媒体接口、包内版本与源码一致性、安装文件清单及原生应用启动检查的实际结果见 Release 的 `Mineradio-2.2.2-build-info.json`。这些检查不等于完成 Windows 安装/卸载交互或 BrimDeck 实机联调。
